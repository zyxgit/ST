# prompt skill

## 适用场景

编写 AI 任务、审查用户需求、拆分路线图、处理不合理需求、文档同步。

## 必须先读

- `docs/ai/README.md`
- `docs/roadmap/README.md`

## 需求审查模板

```text
目标复述：...
合理性判断：合理 / 不合理 / 信息不足
风险：...
推荐方案：...
需要用户确认的问题：...
计划：...
验证：...
```

## 开发规则

- 先判断需求合理性。
- 不合理需求先解释并给优化方案。
- 用户二次确认后才能按不合理方案执行。
- 信息不足时先问，不脑补。
- 一次任务只做一个可评审小目标。

## 禁止事项

- 禁止跳过需求审查。
- 禁止一次性实现整个路线图阶段。
- 禁止最终说明遗漏测试或风险。

## 不确定时必须询问

- 业务规则是否确定？
- 是否允许破坏兼容？
- 是否需要迁移历史数据？
- 是否需要同步前端/部署/文档？

## 验收检查

- `git diff --check`
- 相关后端/前端构建命令
